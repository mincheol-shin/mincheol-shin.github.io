주요 작업

육아로 확장
육아 타임라인과 육아 콘텐츠, 정해진 시간에 열리는 태교 콘텐츠와 인앱 푸시를 만들었습니다.
커뮤니티
게시글·댓글·사진·북마크·차단·검색을 새로 만들고, 화면마다 다르던 컴포넌트를 디자인 시스템으로 묶었습니다.
UI 패키지
Timeline·Linear Chart·날짜 선택·세로 슬라이더 위젯을 만들었고, 그중 날짜 선택과 세로 슬라이더는 회사 동의를 받아 개인 패키지로 정리해 pub.dev에 공개했습니다.
현지화
베트남어·태국어·인도네시아어·일본어·영어를 지원하고 국가별로 기능을 나눴습니다. 사용자가 고른 언어를 모든 요청 헤더에 실어 보내, 서버 푸시도 같은 언어로 받게 했습니다.

문제와 해결

보이는 섹션부터 불러오는 쇼핑 첫 화면

쇼핑 첫 화면은 진입하자마자 모든 섹션의 데이터를 한꺼번에 요청하고, 가장 느린 응답까지 받은 뒤에야 화면을 그렸습니다. 섹션을 컴포넌트로 나누고 화면에 보이는 섹션만 데이터를 요청하도록 지연 로딩으로 바꿔, 화면이 보이기까지 약 5초 걸리던 것을 1초 이하로 줄였습니다. 실기기에서 잰 값입니다.

리드로 정한 구조와 리뷰 규칙

리드를 맡은 뒤 MVVM·Repository와 코드 컨벤션을 정했고, 상태 관리를 Provider에서 Riverpod으로 옮겼습니다. 코드 리뷰도 이끌었습니다. 커뮤니티와 현지화는 이 구조 위에서 더했습니다.
